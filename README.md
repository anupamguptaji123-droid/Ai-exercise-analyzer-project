# 📌 About

The **Exercise Analyzer** is a web application developed using **Python (Flask)** for the backend and **HTML, CSS, and JavaScript** for the frontend.

The application provides a clean interface where users can interact with exercise analysis features. It is lightweight, responsive, and beginner-friendly.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/exercise-analyzer.git
```

Move into project

```bash
cd exercise-analyzer
```

Install Flask

```bash
pip install flask
```

Run Application

```bash
python app.py
```

Open Browser

```
http://127.0.0.1:5000
```
